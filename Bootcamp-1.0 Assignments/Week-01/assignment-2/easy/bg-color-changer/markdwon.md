What is addEventListner() will do.


What is an event:-

An event is something that happens on a webpage.

Examples:-
- User clicks a button.
- User press a key.
- User types in an input box.
- User moves the mouse.
- User scrolls the page.



What does addEventListener() do?

It listens for a specific event and runs some code when that event happens.

element.addEventListener("event", function () {
    // Code to run
});

Like:-
"Hey javascript,watch this element. If this event happens,execute this function"
